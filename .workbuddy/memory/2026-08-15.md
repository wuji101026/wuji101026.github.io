## 按钮动画二次软化（18:11，"还是感觉很硬，该软一点"）
- 根因：上版用 CSS `transition 0.3s` 在每帧 pointermove 时**重启**缓动，本质是"追光标+弹"，仍显硬。
- 改用**连续 lerp 缓动**（rAF 逐帧 `当前 += (目标-当前)*EASE`）：transform 完全由 JS 逐帧插值接管，去掉内联 transition 里的 transform 项（避免双重缓动打架），box-shadow/背景/边框/颜色保留 CSS 缓动。
- 参数：接近半径 `RADIUS` 150→180（更早更柔起步）、跟手强度 0.35/0.22→0.3/0.18、`EASE=0.12`（越小越软越慢）、接近最大迎向 `MAX_PULL*0.6≈6px`。

## 按钮动画改线性匀速（18:14，"太快了，改为线性"）
- 根因：上版指数 lerp（EASE=0.12）是"先快后慢"的 ease-out，用户觉得快且不匀。
- 改：去掉指数缓动，改为**每帧恒定速度朝目标移动**（真·线性）：`SPEED=1.0` px/帧（常量速度，越小越慢）、`SPEED_S=0.008` 控制 scale。距离≤SPEED 时直接吸附归位。整体比 lerp 更慢、速度均匀。
- 手感旋钮：`SPEED`（线性速度，现 1.0）、`RADIUS`(180)、跟手 `s`(0.3/0.18)、`MAX_PULL`(10)。

## 澄清：用户要的是「弹起动画」非磁力跟随（18:17）
- 用户原意："鼠标靠近按钮的动画太生硬 / 软一点 / 线性" 指的是**按钮 hover 的"弹起"（上浮）动画**，不是光标磁力跟随。此前几轮都在调跟随，方向偏了。
- 根因：上浮 `-3px` 嵌在跟随 transform 里，跟着 SPEED=1.0 走，3px 仅 3 帧(~50ms)到位 → 弹起"啪"一下很快。
- 修复：把**弹起高度 `_lift` 与光标跟随 `_x/_y` 解耦**。跟随仍用 SPEED=1.0 线性；弹起单独用 `LIFT_SPEED=0.12` px/帧线性匀速（3px≈25 帧≈417ms 柔和升起，离开同理匀速落下）。transform = translate(_x, _y+_lift) scale(_s)。接近感应里的轻微弹起也改走 `_lift`。
- 手感旋钮新增：`LIFT_SPEED`（弹起速度，现 0.12，越小越柔越慢）。

## 弹起仍太快 → 改为基于时间的匀速（18:20）
- 根因排查：上版 `LIFT_SPEED=0.12` 是**每帧**位移，帧率相关——120/144Hz 高刷屏上实际 0.12×120≈14px/s，3px 仅 ~0.2s，所以"还是太快"。
- 修复：整套运动改为**基于时间（px/秒 × dt）**，与刷新率无关。`SPEED=60`(跟随)、`LIFT_SPEED=4`(弹起→3px≈0.75s)、`SPEED_S=0.5`(scale)。rAF 回调取 `now` 算 `dt`，钳制 ≤0.05s 防跳变。弹起速度由"每帧"改为"每秒"，高刷屏不再翻倍变快。
- 手感旋钮改为秒级：`LIFT_SPEED`(现 4，调小更慢)、`SPEED`(60)、`SPEED_S`(0.5)。

## 弹起改回 ease-out 缓动（18:25，"没有那种动画的感觉，好生硬"）
- 根因：纯线性匀速运动无加减速，到位置骤停 → 机械/生硬，缺动画味。用户要的是"缓动落位感"而非匀速。
- 修复：弹起高度由"每帧匀速"改为**基于时间的 ease-out 缓动 tween**：`_liftP` 进度 0→1，时长 `LIFT_DUR=0.55s`，缓动 `easeOutCubic`(1-(1-t)³)。进入/离开触发 tween（`_liftFrom/_liftTo/_liftT0`，用 performance.now() 与 rAF `now` 同钟），tick 内按 `lt=(now-_liftT0)/1000/LIFT_DUR` 计算缓动进度。
- 结构：跟随(_x,_y)仍时间线性匀速；弹起 hover 走 `_liftP`(eased -3px) + 接近感应 `_plift`(-2t) 合成 `totalLift`；scale 时间线性。彻底与刷新率无关。
- 手感旋钮：`LIFT_DUR`(现 0.55s，调大更慢更柔)、`SPEED`(60)、`RADIUS`(180)、跟手 `s`(0.3/0.18)。
- 经验：按钮 hover 动画要"动画感"必须带 ease（落位），纯线性会显生硬；速度必须用"px/秒×dt"而非"每帧"，否则高刷屏翻倍变快。
